# Checklist de Copy e Funil de Conversão

> Referência para auditoria do Quiz TDAH v1.
> Baseado nas Seções 9, 10 e critérios de conversão da especificação.

---

## 1. Tom de Voz e Linguagem

| Item | Critério | Referência |
|---|---|---|
| TV-01 | Soa como alguém com TDAH que entende TDAH — não psicólogo distante | Spec §10.1 |
| TV-02 | Sujeito sempre "você", nunca "as pessoas com TDAH" | Spec §10.3 |
| TV-03 | Verbos concretos: "perde", "começa", "esquece" | Spec §10.3 |
| TV-04 | Uma ideia por pergunta — sem cenários combinados | Spec §10.3 |
| TV-05 | Tom de conversa entre iguais — não triagem clínica | Spec §10.3 |

## 2. Vocabulário Proibido vs Permitido

| ❌ Evitar | ✅ Usar |
|---|---|
| "déficit" | "TDAH" ou "seu cérebro" |
| "transtorno" | "perfil", "características", "como você funciona" |
| "sintoma" | "traço", "padrão", "característica" |
| "normal" (como meta) | "funcionar do seu jeito" |
| "disciplina" (como solução) | "sistema", "estrutura", "estratégia" |
| "preguiça" | "paralisia de iniciação", "falta de ativação" |
| "você deveria" | "muitos com seu perfil encontram que..." |
| "é fácil" | nunca dizer isso |
| "basta querer" | nunca dizer isso |
| "fracasso" | "ciclo incompleto", "projeto pausado" |
| "problema" | "desafio", "característica", "padrão" |
