# Context pack: copy etica

> **Ticket:** KAN-135 / AGENT-OPS-1
> **Status:** Em analise
> **Dependencias:** `foundation/posicionamento-etico.md`, `foundation/oferta-mvp.md`
> **Sumario:** contexto minimo para copy, promessa, disclaimers, anuncios, e-mail, PDF e checkout.

---

## 1. Quando ler

Leia para qualquer texto publico ou semi-publico: anuncio, landing, quiz, resultado, e-mail, PDF, checkout, Kiwify, termos, garantia, reembolso ou gate.

## 2. Fontes obrigatorias

- `foundation/posicionamento-etico.md`.
- `foundation/oferta-mvp.md`.
- `acquisition/promessa.md` para anuncios e promessa.
- Ticket Jira KAN.

## 3. Regras centrais

- O quiz e autoavaliacao, nao diagnostico.
- Evitar promessa clinica, cura, tratamento, sintoma como rotulo e prova social falsa.
- Urgencia so e aceita se o timestamp for real.
- Preco cheio e cupom devem refletir oferta MVP.

## 4. Validacao

Use `docs/agent-workflows/planner-ethics-copy-review.md`.

## 5. Riscos

- Falso positivo em disclaimers ou exemplos negativos.
- Copy agressiva para publico vulneravel.
- Prova social sem fonte real.
- Promessa maior que o produto PDF entrega.
