# Banco de Capturas Soltas
**Tipo:** [BASE]  
**Páginas estimadas:** 3  
**Status:** Aprovado v1.0 — 2026-05-12

Esta é sua inbox aberta. Use para registrar itens rápidos sem decidir nada na hora. Quando a mente estiver cheia, escreva em uma linha e siga. Depois, processe com calma usando os status: ✓ feito, → delegado, ⏸ incubado, ✗ deletado.

Dica de uso: processe este banco no ritual semanal ou sempre que passar de 20 linhas abertas. O objetivo não é manter a inbox vazia o tempo todo. O objetivo é impedir que tudo fique preso na cabeça.

## Processamento rápido

Escolha uma linha por vez e pergunte:

- Isso ainda importa?
- Existe um próximo passo claro?
- Precisa acontecer esta semana?
- Depende de outra pessoa?
- É uma ideia para incubar, não para executar agora?

Marque o destino e siga para o próximo item. Se perceber que está tentando resolver tudo durante o processamento, pare e escolha apenas três capturas para levar ao ritual diário ou semanal.
