# Identificação do Planner
**Tipo:** [BASE]  
**Páginas estimadas:** 1  
**Status:** Aprovado v1.0 — 2026-05-12

Este planner pertence a uma pessoa real, com dias reais, energia variável, compromissos que mudam e uma atenção que nem sempre segue linha reta. Antes de começar, use esta página como ponto de partida. Ela não precisa ficar perfeita. Ela só precisa dizer: este caderno agora tem um dono, uma intenção e um ciclo para acompanhar.

Preencher esta página ajuda a transformar o planner em uma estrutura pessoal, não em mais um objeto bonito parado na mesa. Se quiser, volte aqui no meio do mês e ajuste a palavra-guia ou a intenção. O plano existe para apoiar seu ritmo, não para prender você em uma versão antiga de si.
