# Ajustes do ritual diário
**Arquétipo:** O Vulcão Silencioso  
**Tipo:** [VARIANTE]  
**Páginas estimadas:** 1-2  
**Status:** Aprovado v1.0 — 2026-05-12

O ritual diário base organiza energia, intenção e prioridades. Para este perfil, a adaptação principal é reconhecer o estado emocional antes de definir o tamanho do dia. O plano precisa caber no que está acontecendo por dentro, não apenas no que aparece na agenda.

## 1. Comece pelo check-in de humor

Antes de escrever prioridades, marque uma palavra:

- calmo;
- tenso;
- irritado;
- sensível;
- acelerado;
- drenado;
- esperançoso;
- em alerta.

Depois responda:

**O que esse humor pede do meu planejamento hoje?**

Exemplos:

- Se estou sensível, vou evitar tarefas que exigem exposição sem preparo.
- Se estou em alerta, vou reduzir decisões e aumentar passos claros.
- Se estou drenado, vou escolher a versão mínima do dia.
- Se estou esperançoso, vou avançar sem encher a lista.

## 2. Escolha uma das três versões do dia

Antes das prioridades, defina o tamanho do plano.

| Versão | Quando usar | Como preencher |
|---|---|---|
| Mínima | Humor pesado, pouco espaço interno, dia com fricção alta. | 1 prioridade pequena + 1 cuidado de retomada. |
| Média | Energia suficiente, mas com risco de oscilação. | 2 prioridades reais + 1 buffer. |
| Completa | Dia com espaço interno e agenda mais previsível. | Até 3 prioridades + revisão noturna completa. |

Essa escolha evita planejar pela expectativa mais alta quando o dia pede uma entrada menor.

## 3. Inclua buffer pós-erro ou pós-crítica

Se existe uma reunião, entrega, conversa ou tarefa com chance de mexer com você, reserve um buffer logo depois.

O buffer pode ser:

- 10 minutos sem nova demanda;
- uma caminhada curta;
- água e respiração;
- uma anotação livre;
- uma tarefa manual simples;
- uma mensagem só depois de reler.

Regra: depois de um evento sensível, não tomar uma decisão grande nos primeiros minutos.

## 4. Crie uma tarefa de reentrada

Quando algo desestabilizar, a página precisa ter uma porta pequena. Escreva uma tarefa que pareça quase pequena demais:

- abrir o arquivo;
- reler o último parágrafo;
- responder apenas "recebi";
- separar o material;
- riscar o que saiu do dia;
- copiar a pendência para a captura.

A tarefa de reentrada existe para quebrar o gelo, não para resolver tudo.

## 5. Use a caixa "não hoje"

Acrescente ao ritual uma caixa com este título:

**O que não precisa ser resolvido hoje**

Use para tirar da cabeça temas que estão ocupando espaço, mas não precisam de ação imediata. Isso reduz o peso invisível do dia.

## 6. Fechamento sem autocrítica longa

No fechamento, responda só:

1. Qual versão do dia eu vivi de fato?
2. O que me ajudou a voltar?
3. O que precisa de buffer amanhã?

Não use a revisão para se julgar. Use para calibrar o próximo tamanho de plano.
