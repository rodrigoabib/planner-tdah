# Boas-vindas
**Arquétipo:** O Furacão  
**Tipo:** [VARIANTE]  
**Páginas estimadas:** 1  
**Status:** Aprovado v1.0 — 2026-05-12

Quando tudo chega forte ao mesmo tempo, um planner cheio de etapas vira mais uma coisa competindo pela sua cabeça. Energia, urgência, emoção, distração, mensagem, vontade de resolver tudo, vontade de sair de tudo: às vezes o dia começa antes de você conseguir escolher a direção.

Por isso, esta versão trabalha com simplicidade radical. O objetivo não é preencher mais. É reduzir a superfície de decisão. Se houver muitas caixas, muitos planos e muitas promessas, o sistema quebra. Então a regra principal é clara: 1 a 3 prioridades absolutas por dia. Nada além disso precisa disputar o centro.

Cada prioridade terá uma versão mínima. Isso importa porque dias intensos mudam rápido. Se o plano completo estourar, você não perde o dia inteiro. Você volta para o menor passo que ainda mantém a intenção viva.

Este planner também usa reset sem punição. Reset não é bronca. Não é recomeçar do zero com raiva. É só o procedimento de voltar para o que ainda cabe. Riscar, reduzir, escolher uma ação e seguir.

Para este perfil, menos não é pouco. Menos é o que permite continuar quando tudo tenta acontecer ao mesmo tempo.

## Como começar hoje

1. Escolha uma prioridade principal.
2. Se couber, escolha mais duas. Pare em três.
3. Escreva a versão mínima de cada uma.
4. Marque o que pode ser descartado temporariamente.
5. Deixe o reset de 5 minutos pronto para usar.

Se o dia sair do eixo, não negocie com a lista inteira. Volte para uma prioridade absoluta e uma ação mínima.
