# Ajustes do ritual diário
**Arquétipo:** Perfil de manutenção lowSeverity  
**Tipo:** [VARIANTE]  
**Páginas estimadas:** 1-2  
**Status:** Aprovado v1.0 — 2026-05-12

O ritual diário base pode ser usado por completo, mas esta versão não exige isso todos os dias. Para este perfil, a adaptação principal é alternar entre modo curto e modo completo conforme a carga real do dia.

## 1. Use a versão curta como padrão

Em dias comuns, preencha apenas:

- data;
- energia de 1 a 5;
- intenção do dia;
- uma prioridade principal;
- uma captura solta, se houver.

Isso mantém o contato com a estrutura sem excesso de preenchimento.

## 2. Abra o template completo só quando precisar

Use a versão completa do ritual diário quando aparecer pelo menos um destes sinais:

- muitas pendências competindo;
- compromisso importante com risco de escapar;
- dia com trocas de contexto;
- energia baixa e lista nebulosa;
- semana acumulada;
- decisão que precisa de clareza.

Se nenhum sinal estiver presente, a versão curta é suficiente.

## 3. Marque atritos recorrentes

Crie uma linha chamada:

**Atrito que se repetiu**

Exemplos:

- esqueci de conferir a agenda antes de sair;
- deixei uma pendência pequena crescer;
- aceitei algo sem ver a semana;
- comecei tarde porque a primeira ação estava vaga;
- não fechei o dia e carreguei pendência para a cabeça.

O objetivo não é registrar tudo. É perceber padrões pequenos antes que virem acúmulo.

## 4. Revise semanalmente sem excesso

Na revisão semanal, responda só:

1. O que funcionou com pouco esforço?
2. Qual atrito apareceu mais de uma vez?
3. Que ajuste simples evita repetição?
4. Qual template vale usar na próxima semana?

Evite transformar revisão em inventário completo da vida. Quatro respostas bastam.

## 5. Use templates por necessidade, não por obrigação

Templates diários, semanais e mensais são ferramentas. Abra quando eles reduzem atrito:

- template diário para dias confusos;
- template semanal para escolher foco;
- template mensal para enxergar ciclos;
- banco de captura quando a cabeça estiver cheia.

Se o template não reduz atrito naquele momento, deixe para depois.

## 6. Fechamento de manutenção

No fim do dia, marque apenas:

- uma coisa que avançou;
- uma coisa que pode esperar;
- um atrito a observar.

Essa revisão curta preserva continuidade sem criar peso desnecessário.
