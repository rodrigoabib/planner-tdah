# Análise Estrutural do Repositório — Projeto “Planner TDAH”

## Objetivo

Use o conector do GitHub para analisar cuidadosamente o repositório referente ao projeto **“Planner TDAH”**.

O objetivo desta análise inicial é compreender, com profundidade, a proposta do produto, o público-alvo, a estrutura do planner e o conteúdo dos documentos Markdown existentes no repositório, especialmente os documentos localizados dentro da pasta `product`.

Neste momento, **não quero sugestões de design visual** mas tenha em mente que eu irei focar bastante as minhas perguntas e solicitações posterior a você, em queestões relacionadas à propostas de design e identidade visual para esse projeto, se usar o design atual como referência, principalmente no que diz respeito à experiência do usuário em relação ao planner, principalmente se tratando de pessoas com TDAH. A análise deve focar exclusivamente em:

- Conteúdo;
- Estrutura do planner;
- Proposta do produto;
- Público-alvo;
- Organização das seções;
- Lógica dos arquétipos;
- Clareza, coerência e completude do material;
- Relação entre o planner e as necessidades de pessoas com TDAH.

---

## Repositório

Analise o seguinte repositório do GitHub: `rodrigoabib/planner-tdah`

Caso o repositório não esteja acessível, solicite apenas a informação estritamente necessária para prosseguir.

---

## Escopo da análise

### 1. Compreensão geral do projeto

Primeiro, faça uma leitura geral do repositório para entender:

- O que é o projeto “Planner TDAH”;
- Qual é a proposta principal do produto;
- Qual problema ele pretende resolver;
- Quem é o público-alvo;
- Como o planner está estruturado;
- Como o produto parece estar sendo pensado como infoproduto vendável na internet.

---

### 2. Documento de escopo

Em seguida, localize e analise o documento Markdown de escopo que está dentro da pasta chamada `Quiz`.

Esse documento deve ser usado como uma das principais referências para compreender:

- A origem da proposta;
- A lógica do produto;
- A relação entre o quiz e o planner;
- Os arquétipos ou perfis definidos;
- Como o resultado do quiz se conecta à experiência final do usuário.

---

### 3. Documentos de foundation

Depois, analise os documentos relacionados à parte de `foundation`, caso existam no repositório.

Considere esses documentos como materiais de base conceitual do produto.

Procure entender:

- Quais princípios orientam o planner;
- Quais conceitos são usados para sustentar a proposta;
- Como esses conceitos se conectam ao TDAH;
- Quais premissas aparecem sobre comportamento, produtividade, rotina, organização, foco, emoções ou autogestão.

---

### 4. Pasta `product`

Esta é a parte mais importante da análise.

Analise com extrema atenção todos os arquivos Markdown existentes dentro da pasta `product`, incluindo todas as suas subpastas.

Esses documentos representam a estrutura completa do PDF do **Planner TDAH**, que será vendido como infoproduto.

Durante essa análise, identifique e compreenda:

- A estrutura geral do planner;
- As seções comuns a todos os arquétipos;
- As seções específicas de cada arquétipo;
- A lógica de progressão do conteúdo;
- A função de cada página ou bloco de conteúdo;
- Como o planner pretende ajudar pessoas com TDAH;
- Quais dores, dificuldades ou necessidades do público-alvo são abordadas;
- Como o conteúdo se adapta aos diferentes perfis/arquetípicos;
- Se existe repetição, lacuna, inconsistência ou sobreposição entre os documentos;
- Como o material se organiza como um produto final em PDF.

## Foco principal da análise

O foco deve ser compreender profundamente:

1. **O produto**
   - O que é o Planner TDAH;
   - Como ele funciona;
   - Qual transformação ele promete entregar;
   - Como ele se diferencia de um planner genérico.

2. **O público-alvo**
   - Pessoas com TDAH;
   - Suas dores práticas;
   - Suas dificuldades emocionais e cognitivas;
   - Suas necessidades de organização, rotina, foco e autogestão.

3. **A estrutura do conteúdo**
   - Como o planner está dividido;
   - Quais partes são comuns;
   - Quais partes são personalizadas por arquétipo;

4. **A lógica dos arquétipos**
   - Quais arquétipos existem;
   - Como cada arquétipo é caracterizado;
   - Como o planner se adapta a cada um;
   - Quais conteúdos são específicos para cada perfil.
